# Jontu Chhaas Masala Website

This is a premium, modern, and fully responsive website for the brand "Jontu Chhaas Masala". It is built with pure HTML, CSS, and Vanilla JavaScript, following best practices for performance, SEO, and UI/UX design.

## Features

-   **Stunning Design:** A luxurious and professional look that reflects the premium quality of the brand.
-   **Fully Responsive:** Perfect viewing experience on all devices, from mobile phones to desktops.
-   **Smooth Animations:** Engaging animations and transitions throughout the site, built with CSS and JavaScript, and respectful of `prefers-reduced-motion`.
-   **SEO Optimized:** Built with SEO best practices, including semantic HTML, meta tags, and a sitemap.
-   **Performance Focused:** Optimized for fast loading times with lazy-loaded images and clean code.
-   **No Frameworks:** Built with just HTML, CSS, and Vanilla JS - no jQuery, Bootstrap, or other libraries.

## Website Sections

1.  **Loader:** Animated loading screen.
2.  **Sticky Navigation:** Glassmorphism navigation that becomes solid on scroll.
3.  **Hero Section:** Eye-catching intro with an animated product bottle.
4.  **About:** Company story and values.
5.  **Why Choose Us:** Highlights key features of the product.
6.  **Ingredients:** A showcase of the natural ingredients.
7.  **How To Use:** A simple, visual guide.
8.  **Product Showcase:** Displays the different product sizes.
9.  **Gallery:** A beautiful masonry photo gallery.
10. **Testimonials:** Customer reviews.
11. **FAQ:** An accordion for common questions.
12. **Contact:** Contact form, address, and social media links.
13. **Footer:** Site links and copyright information.

## How to Run

1.  Clone this repository or download the files.
2.  Open the `index.html` file in your web browser.

No special build steps or dependencies are required. It's a pure static website.
